# Personal Expense Tracker with CSV

## Project Description

This is a beginner-friendly Python application that helps users record, manage, and track their daily expenses by category. It uses CSV file handling to store expense records permanently.

## Features

- Add daily expenses
- View all recorded expenses
- Filter expenses by category
- Store expense details in a CSV file
- Calculate total expenses
- Generate category-wise expense summaries

## Technologies Used

- Python 3
- Python IDLE
- CSV Module

## Concepts Covered

- Variables and data types
- Conditional statements
- Loops
- Functions
- File handling
- CSV read and write operations
- Lists and dictionaries
- Data processing and summary statistics

## How to Run

1. Download the Python file.
2. Install Python 3.
3. Open the file using Python IDLE.
4. Press F5 to run the program.
5. Enter expense details and manage your daily spending.
